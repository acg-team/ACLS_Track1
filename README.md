Welcome to Track 1 Specialisation in the Bioinformatics Centre!

For this module, you will be joining regular weekly sessions in the first half of the semester. You will find the slides in the corresponding directory above. 
You will be meeting group members in the centre, learn about their research.
You will also be given an introduction to relevant bioinformatics approaches in the field. Please find the program up above. 
We will then introduce you some possible projects that you can work on in the second part of the semester. We expect you to spend majority of your module hours into this project.
You will be expected to hand in a written report (roughly 10 pages including everything). The format is flexible. 
Please make sure to include a Statement of AI Use in your report detailing when and how exactly you used AI.

The details to the projects you will also find in this repo.
